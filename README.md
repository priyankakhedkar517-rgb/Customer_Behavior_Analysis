# Customer Behavior Analysis

## Project Overview
Analyzed customer purchasing patterns, spending habits, and purchase frequency using Python, Pandas, SQL, PostgreSQL, and Power BI.

## Tools Used
- Python
- Pandas
- SQL
- PostgreSQL
- Power BI

## Project Files
- `customer_behavior_analysis.ipynb` – Python data analysis
- `customer_behavior_analysis_Dashboard.pbix` – Power BI dashboard

## Objective
To understand customer behavior and identify purchasing trends through data analysis and visualization.
